Linux Locale Editor

Compose your own Linux locale with section-by-section inheritance, international presets, and formatted glibc previews. Native GTK interface for Xfce, plus an MC-style terminal editor.

Source and documentation · Release downloads · APT maintenance and key details

Compatibility: current Kali Linux, amd64 or arm64, with glibc 2.43 or later. These packages are not older Debian/Ubuntu compatibility builds.

Add the signed APT source

Download the archive key and compare its full fingerprint:

curl --fail --location --output locale-editor-archive-keyring.asc \
  https://cubiculum-ai.github.io/locale-editor/apt/locale-editor-archive-keyring.asc
gpg --show-keys --fingerprint locale-editor-archive-keyring.asc

Expected fingerprint:
EA28 F95D 0277 0287 7D25 A156 1162 D8DB 633F 745C

After verifying it, add the per-source keyring and repository:

sudo install -d -m 0755 /etc/apt/keyrings
sudo install -m 0644 locale-editor-archive-keyring.asc /etc/apt/keyrings/locale-editor-archive-keyring.asc
sudo tee /etc/apt/sources.list.d/locale-editor.sources >/dev/null <<'SOURCES'
Types: deb
URIs: https://cubiculum-ai.github.io/locale-editor/apt/
Suites: stable
Components: main
Architectures: amd64 arm64
Signed-By: /etc/apt/keyrings/locale-editor-archive-keyring.asc
SOURCES
sudo apt update
sudo apt install locale-editor-gui
# For a headless machine instead:
# sudo apt install locale-editor-tui

Use and update

locale-editor launches the GUI in the GUI edition. locale-editor-tui launches the terminal interface. System-wide locale installation uses polkit administrator authentication; personal installation needs no administrator privileges.

Update normally with sudo apt update and sudo apt upgrade. Installing these packages does not change your default locale.

Repository metadata is signed and expires after 90 days. Signature, expiry, and package-hash checks remain enabled. Never use trusted=yes or disable authentication checks.
